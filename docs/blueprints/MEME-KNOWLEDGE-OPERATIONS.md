# Meme Knowledge Operations Split

## Canonical source
`Sable Brain` is the human-authored source of truth.

Use it for:
- humor theory
- case studies
- lexicon notes
- prompt iteration
- feedback rules
- page voice

## Runtime cache
CopeNet generates a JSON index from the markdown vault.

Use it for:
- compact retrieval
- deterministic pack assembly
- runtime prompt composition
- testable knowledge selection

## Future optional store
A separate event or analytics store may exist later for:
- human ranking feedback
- retrieval telemetry
- candidate quality analytics
- judge outcomes over time

This future store should not replace the markdown vault as the canonical authoring system.
